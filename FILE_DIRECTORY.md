## Key Decisions Made

### Architecture
- **Single Responsibility** - Each component/hook has one job
- **Type Safety** - Full TypeScript strictness enabled
- **Reusable Components** - UI elements can be used across pages
- **State Management** - Zustand for lightweight, scoped stores
- **Custom Hooks** - Encapsulate common logic patterns

### Styling
- **Tailwind CSS** - Utility-first, fast development
- **Dark Theme** - Professional for traders, reduces eye strain
- **Glass Morphism** - Modern, sophisticated look
- **Responsive Design** - Mobile-first approach

### Web3 Integration
- **Wagmi Hooks** - React-first Web3 library (configured, ready to use)
- **Contract ABIs** - Minimal ABIs provided, ready for full ones
- **Type Safety** - Smart contract types in TypeScript
- **Event Listeners** - Web3 event patterns established

### Data Visualization
- **Recharts** - Lightweight, customizable, responsive charts
- **Mock Data** - Realistic data for demonstration
- **Real-time Ready** - Charts structured for live data updates

## Quick File Reference Guide

**Need to...**

- **Add a new page?** → Follow pattern in `app/*.tsx`, import Header, use Card/Button
- **Create reusable component?** → Add to `components/`, export from index if needed
- **Add state?** → Create hook in `store/index.ts` using Zustand
- **Format data?** → Use functions from `utils/format.ts`
- **Handle async?** → Use `useAsync` hook from `hooks/index.ts`
- **Style something?** → Use Tailwind classes or add to `globals.css`
- **Connect to contract?** → Follow pattern in `INTEGRATION_GUIDE.md`
- **Add types?** → Add interface to `types/index.ts`
